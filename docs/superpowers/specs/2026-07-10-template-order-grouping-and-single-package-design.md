# 模板顺序、L1 结果组合与单对象导入导出设计

## 背景与目标

客户要求三级模板的关联顺序可手动维护，并让项目页面及 Excel 前置清单、结果清单和导出 Sheet 均遵循该顺序。客户还要求将多个独立 L1 表组合为一个结果项，例如“火灾报警设施-自动 / 手动 / 控制器”分别录入和导出，但以“火灾报警设施”展示点位、检查体系和最终完好率。

此外，需要支持项目、L1、L2、L3 模板的单独导入和导出，且不会覆盖本机既有数据。

## 方案选择

采用“模板定义默认规则，项目保存独立快照”的方案。

- L1 模板定义结果组合名称和组合权值；L2/L3 模板数组定义关联顺序。
- 项目新增 L1 时，将 L1 组合配置写入项目级点位条目和点检数据中，作为后续计算和导出的快照。
- 修改模板不会反向改写已创建项目；旧项目继续使用其现有的项目级组合字段。
- 单对象导入导出使用携带依赖的 JSON 包；发生 ID 冲突时导入为副本并重映射关联 ID，绝不默认覆盖本机数据。

该方案符合项目“模板修改不影响已有项目”的数据一致性约束，也避免项目中重复维护同一 L1 的组合规则。

## 数据模型

### L1 模板

向 `L1Template` 增加可选字段：

```ts
resultGroupName?: string
resultWeight?: number
```

- `resultGroupName` 为空时，该 L1 独立展示和计算。
- 同一 L2 中、名称相同且非空的 L1 组成一个结果项。
- `resultWeight` 默认为 `1`；权值为 `0` 的 L1 不参与组合完好率加权平均。

### 项目快照

继续使用 `ProjectLocationItem` 与 `InspectionTableData` 上已有的 `resultGroupName`、`resultWeight` 字段。

- 创建项目向导、项目点位清单新增 L1 时，以 L1 模板值初始化快照。
- 项目内不再显示或编辑这两个字段。
- 旧项目不回填模板新值，防止修改模板后改变历史项目结果。

## 顺序规则

### 模板编辑

- L2 模板的关联 L1 区保留穿梭框；右侧新增已关联顺序清单，支持上移和下移。
- L3 模板采用相同方式维护关联 L2 的顺序；现有 L3 分部权值面板跟随该顺序排列。
- 顺序直接保存到 `availableL1Ids` 与 `availableL2Ids`，无需引入额外排序字段。

### 消费顺序

- 新建项目向导按 L3 `availableL2Ids`、L2 `availableL1Ids` 生成条目。
- 项目中分部 Tab、L1 Tab、点位清单、检查体系结构、结果清单、检查结果计算表和各级导出均以模板数组顺序为主。
- 项目中只选择了部分关联项时，保留模板排序并跳过未选择项。
- 清单和表格序号在最终输出阶段连续重编号为 `1、2、3……`；不得暴露原数组下标或历史编号间隙。

## 组合后的展示与计算

对于同一 L2 内同名组合：

- L1 点检表仍独立保存、录入与导出。
- 点位清单按 L1 顺序把各子表的点位名称串接为一个设施条目；数量为各子表数量之和。
- 检查体系结构只合并“设施名称”列，子表的检查项目和主要检测内容按 L1 顺序连续输出。
- 结果清单、L2 和 L3 仅显示一行组合名称；设备总数与故障台数为子表合计，设备完好率为子表完好率按组合权值的加权平均。
- 未设置组合名称的 L1 保持原有独立行为。

## L1 Excel 分页

当前页内多表块的余高会平均加到所有备注行，导致中间间隔视觉不均。改为：

- 表块之间始终使用固定间隔。
- 页面剩余高度只追加到该页最底部最后一个有效表块的备注区域。
- 下一个完整表块无法放入时直接换页，不压缩或拉伸前面表块间隔。
- 最终汇总块及独立备注页的现有规则继续保留。

## 单对象导入与导出

新增版本化 JSON 包，包含 `app`、`packageVersion`、`rootType`、`exportedAt` 和依赖数据。

| 根对象 | 包含的依赖 |
| --- | --- |
| 项目 | 关联 L3、L2、L1 模板及这些 L1 引用的设备库条目 |
| L3 模板 | 关联 L2、L1 模板及设备库条目 |
| L2 模板 | 关联 L1 模板及设备库条目 |
| L1 模板 | 该 L1 引用的设备库条目 |

导入流程：

1. 校验应用标识、包版本、根对象类型和 JSON 结构。
2. 检查依赖关系，记录缺失或无效引用并中止导入。
3. 对已存在的 ID 生成新 ID，并同步重写包内所有引用。
4. 根对象和依赖均以“导入副本”保存；名称冲突时添加“（导入）”后缀。
5. 刷新对应 Pinia Store；全量备份的整体替换流程不作改变。

导出入口位于项目管理和模板管理的对象操作区；导入入口按项目、L1、L2、L3 分类显示，防止把错误类型导入到错误区域。

## 兼容性与验证

- 缺少新增 L1 字段的旧模板按“未组合、权值 1”处理。
- 旧项目保持项目级快照，导入后结果不因模板新字段变化而变化。
- 需要验证顺序贯穿 UI、前置清单、结果清单及全部导出 Sheet。
- 需要使用提供的隧道检查备份构造组合 L1 回归样本，核对点位清单、检查体系结构、结果清单与 L1 独立 Sheet。
- 需要覆盖三表同页、页尾两表和独立备注页，确认只有最底部备注区域拉伸。
- 完成 `vue-tsc --noEmit`、生产构建、`git diff --check` 与定向 Excel 导出检查。
